# Unity 平头六边形模型切割工具

## 安装与打开

1. 在 Unity 中通过 `Assets > Import Package > Custom Package…` 导入 `HexGridCutter.unitypackage`；或者解压源码 ZIP，将其中 `Assets/HexGridCutter` 复制进项目的 `Assets`。
2. 等待脚本编译，在菜单中打开 **Tools > Hex Grid Cutter > 打开切割工具**。
3. 将场景中的模型根节点拖到“源模型 / 层级根节点”，或先选中模型，再点“使用当前选中对象”。
4. 若模型不可读：在 Project 中选中 FBX / 模型文件，在 Inspector 的 Model 导入设置中启用 **Read/Write** 并 Apply。
5. 设置半径、原点和输出目录，选择是否开启“切割断面自动封口”，点击“切割并保存 Prefab”。

建议先在项目副本或测试场景中，用较大的半径试切。工具不会改写原 Mesh、材质或模型导入设置。

## 你需要的 Toggle

**切割断面自动封口（实体模型开启 / 地表薄片关闭）**

- **关闭**：只裁剪原始三角形。适合地表、薄片地形；不会凭空生成底面或侧壁。
- **开启**：在六个竖直裁剪平面上补面。适合独立闭合的实体网格；支持不相连的闭合轮廓、凹轮廓和孔洞。
- 开启封口不是“修复模型”。原网格已有的破洞、非流形边、自相交、相接的轮廓、重叠实体、重合重复面不保证可用；检测到无法闭合的切口会报错并清理本批次，而不是输出明显错误的封口。
- 每个 **MeshFilter** 独立裁剪、独立封口。一个闭合模型即使有多个材质，只要仍属于同一个 MeshFilter 就可以；若外壳被拆成多个各自不闭合的 MeshFilter，请先合并网格再封口。
- 嵌套轮廓按奇偶规则处理：外轮廓填充、内轮廓留孔。重叠实体不执行布尔并集，请先在建模软件中合并。
- 不支持直接切 Terrain 组件或 SkinnedMeshRenderer。Terrain 请先转静态 Mesh；骨骼模型请先烘焙。含 LODGroup 的根节点会被拒绝，以防多个 LOD 重叠切出；可只选其中一个 LOD 的子节点。

## 网格定义：平头，不是尖头

网格坐标系的水平面为 XZ，Y 轴为高度。绕世界 Y 轴的旋转由“网格 Y 轴旋转”设置；不支持倾斜网格平面。切割沿高度方向无限贯穿，不分层。

`R = 六边形中心到顶点的距离 = 边长`（世界单位）。

- 外接宽度（X）：`2R`
- 上下平边距离（Z）：`√3R`
- 相邻列的中心 X 距离：`1.5R`
- 同列相邻格子的中心 Z 距离：`√3R`

采用平头轴向坐标 `(q, r)`：

```csharp
Vector3 center = new Vector3(
    1.5f * radius * q,
    0f,
    Mathf.Sqrt(3f) * radius * (r + 0.5f * q)
);
Vector3 worldCenter = gridOrigin + Quaternion.Euler(0f, gridYaw, 0f) * center;
```

网格原点对应 `(q=0, r=0)` 的中心。源模型的平移、旋转、层级变换、非均匀缩放和负缩放会烘焙进输出网格。原点 Y 决定所有 Prefab 的公共高度基准，不会把各格子自动吸附到地面。

## 输出内容与拼回方式

每次导出都会创建独立的、不覆盖旧文件的批次目录：

```text
Assets/HexGridOutput/<模型名称>_<时间戳>/
    Meshes/  Hex_q0_r0_0_<网格名称>.asset
    Prefabs/ Hex_q0_r0.prefab
             Hex_q1_r0.prefab
             Hex_q-1_r1.prefab
             ...
```

- 每个非空格子一个 Prefab；空格子不保存。
- 一个格子包含多个原始 MeshFilter 时，Prefab 内有多个网格子节点。
- Mesh 会保存为真正的 `.asset`，Prefab 引用这些资源，不依赖临时内存 Mesh。
- Prefab 根节点的位置为零、旋转为单位旋转、缩放为一。网格顶点相对该格子的中心存储。
- 根节点带有轻量的运行时 `HexCellData` 组件，包含 `Q / R / Radius / OriginalGridOrigin / OriginalGridYaw`。
- 开启“完成后在场景中拼回”时，会生成 `<模型名称>_HexMap`，按照原点、旋转和坐标还原；可以 Undo 删除这个场景容器，**Undo 不会删除已经保存的资源**。
- **原模型保持可见且不被删除。** 查看新结果前，请手动隐藏原模型，避免两份重叠闪烁。

运行时拼格子示例（父节点已经位于地图原点，并绕 Y 轴旋转至地图角度）：

```csharp
using HexGridCutter;
using UnityEngine;

public static class HexPlacement
{
    public static GameObject Place(GameObject prefab, Transform mapRoot)
    {
        var instance = Object.Instantiate(prefab, mapRoot);
        var data = instance.GetComponent<HexCellData>();
        instance.transform.localPosition = data.GridCenter;
        instance.transform.localRotation = Quaternion.identity;
        instance.transform.localScale = Vector3.one;
        return instance;
    }
}
```

相邻六个轴向邻居的偏移为 `(1,0), (1,-1), (0,-1), (-1,0), (-1,1), (0,1)`。

## 材质与顶点数据

- 保留每个源网格的三角形子网格和材质引用；不复制材质或贴图文件。
- 裁剪时线性插值 UV0–UV7、顶点颜色、法线和切线；输出法线归一化、切线重新正交化。
- 没有法线时按原三角形计算面法线；没有切线时由输出 UV0 重新计算。
- 封口使用单独的子网格和硬边法线。可指定“封口材质”，未指定时使用对应源网格的第一个材质。
- 封口 UV0 使用切面上的平面投影，“封口 UV 平铺 / 单位”控制比例；封口的其他 UV 通道默认零，顶点颜色为白色。
- 有光照贴图需求时可开启“重新生成光照贴图 UV2”，这会重做第二套 UV；已有烘焙光照索引不复制，需要重新烘焙。
- 顶点以每个三角形独立顶点形式输出，以保留材质边界和硬边属性。文件及顶点数可能增加；超过 65,535 个顶点时使用 UInt32 索引。
- 源材质兼容何种渲染管线，输出就使用相同材质；本工具不包含专用 Shader，不进行 Built-in / URP / HDRP 材质转换。
- 不复制原对象脚本、动画、骨骼、BlendShape、LOD 配置、静态批处理标记、MaterialPropertyBlock、灯光或原碰撞体。

## 可选碰撞体

“添加静态 MeshCollider”会在每个网格子节点上添加非凸 MeshCollider。默认关闭，用于静态地图；不会自动创建 Rigidbody，也不把任意复杂格子转成可动态模拟的凸碰撞体。

## 性能、数值限制与错误恢复

- 六边形网格预览显示在原点高度的平面上，不是贴合地表的轮廓；预览候选格子超过 1000 时隐藏。
- 每次最多处理 10,000 个候选格子。过小半径会产生大量 Prefab，应增大半径或拆分输入。
- 封口模式为了保持中间裁剪结果的闭合，需要逐格扫描相关源网格；大模型 / 很多格子时耗时和内存占用明显增加。预计工作量较大时先弹出提示。
- 可在进度窗口取消；取消检查发生在格子之间，当前格子的运算结束后才响应。超大单个格子可能暂时让编辑器无响应。
- 实际容差为 `Max(R × 相对数值容差, 0.000001)`。默认相对容差 `0.00001`。极小细节、接触壳体、重合切口、尺度悬殊或大坐标会影响结果；原点尽量放在模型附近。
- 裁剪面上的零体积接触片可能被忽略；不保证对恰好重合的薄片进行唯一归属分配。
- 不提供“任何坏网格都能封口”的保证；请检查复杂资产的切口、孔洞和材质效果。
- 导出失败或正常取消会删除**此次新建批次目录**，保留旧批次和源资产。编辑器崩溃、进程被强制结束或磁盘异常时无法保证清理。
- 输出目录必须位于当前项目 `Assets` 内；路径中的 `..` 被拒绝。

## 自检与验证

菜单 **Tools > Hex Grid Cutter > 运行自检** 可在你的项目中运行自带测试。测试使用临时场景对象和独立临时资源目录，正常完成或抛出异常后清理。

随下载提供的 `validation-report` 记录实际运行的 Unity 版本、通过项和错误（若有）。仅对报告中的版本声称实际验证；其他版本请在项目副本中先运行自检。

## 文件结构与第三方许可

- `Runtime/HexCellData.cs`：运行时坐标元数据。
- `Editor/HexGeometry.cs`：变换、插值、六平面裁剪、轮廓重建、封口、Mesh 构建。
- `Editor/HexGridCutterWindow.cs`：界面、网格预览、资源导出、场景拼接和回滚。
- `Editor/HexGridCutterSelfTest.cs`：可重复运行的几何与导出自检。
- `Editor/ThirdParty/LibTessDotNet`：封口轮廓三角化依赖，已经随包提供，不需额外安装。

LibTessDotNet 来自 speps/LibTessDotNet，固定提交 `bdc0b0f94904dd94c3edfb2c25aa358695276e09`。
